Emergency Resource Locator

A lightweight web app that helps users quickly find nearby **hospitals, ambulances, and blood banks**, even in **low-network emergency situations**.

⚡ What It Does
- Detects user location
- Shows nearest emergency resources
- Enables one-tap calling
- Displays offline emergency numbers (108 / 100 / 101)
- Stores no personal data

 🛠️ Tech Stack
HTML, CSS, JavaScript · Flask (Python) · SQLite · C (distance logic) · OpenStreetMap

 🚀 Future Scope
Live ambulance tracking · Hospital availability · Mobile app · Govt. integration

 🔐 Privacy
No user data collected.
